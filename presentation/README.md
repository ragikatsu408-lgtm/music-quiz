# Поэтизация речи

Веб-слайды по риторике: как заменить обыденные и деловые фразы цитатами, метафорами и аллюзиями.

Викторина Music Quiz в корне репозитория не зависит от этой папки.

## Запуск

```bash
cd presentation
npm install
npm run dev
```

Сервер: `http://127.0.0.1:47391` (порт не пересекается с викториной на `46231`).

## Навигация

- Клавиши **←** и **→**, пробел, PageUp / PageDown
- Клик по слайду: правая зона — вперёд, левая (~28%) — назад
- Кнопки **←** **→** внизу
- Свайп на телефоне
- **Esc** — оглавление
- Индикатор прогресса и счётчик слайдов
