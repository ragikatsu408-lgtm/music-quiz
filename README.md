# Музыкальный класс

Веб-приложение на Vite (HTML, CSS, vanilla JavaScript): учитель собирает викторину и открывает комнату, ученик входит по шестизначному коду.

Встроенные режимы те же, что раньше: мелодия по фрагменту, инструмент по фото, композитор по портрету, пение в микрофон. Их можно запускать из кабинета учителя как обычную комнату.

Фрагменты — синтезированные публичные мелодии в `public/audio/`. Фото — в `public/images/`.

## Как запустить локально

Нужны Node.js 20+ и npm.

```bash
npm install
python3 scripts/generate-audio.py   # если WAV-файлов ещё нет
npm run dev
```

Откройте адрес, который напечатает Vite. Dev-сервер слушает порт **46231** (`http://127.0.0.1:46231/`).

Сборка:

```bash
npm run build
npm run preview
```

## Как проверить учителя и ученика (две вкладки)

На этой машине `*.supabase.co` часто не резолвится. Класс всё равно работает **локально в одном браузере**: `localStorage` + `BroadcastChannel`.

1. Откройте две вкладки на `http://127.0.0.1:46231/`.
2. Вкладка 1: **Я Учитель** → выберите встроенный режим (например «Мелодия») или сохраните свою викторину и нажмите **Код**.
3. На экране появится шестизначный код. Если Supabase недоступен, красная плашка об этом — это нормально, комната всё равно живая.
4. Вкладка 2: на главной введите имя и тот же код → **Войти в комнату**.
5. Пройдите вопросы (аудио, карточки ответов, таймер, «Вопрос 3 из 10»).
6. На итогах ученика — счёт, баллы и короткая оценка. Во вкладке учителя откройте **Результаты**: имя, баллы, процент, время, самые частые ошибки.

Создать свою викторину: кабинет → **Новая викторина** → формулировка, URL трека или загрузка файла, четыре варианта, правильный ответ → **Сохранить** → **Код**.

## Supabase

Счёт соло-игры пишется в таблицу `scores`. Комнаты, викторины и попытки учеников — в таблицы из `supabase/classroom.sql`.

1. Скопируйте `.env.example` в `.env` (файл `.env` в git не коммитьте).
2. `VITE_SUPABASE_URL` уже указан. В `VITE_SUPABASE_ANON_KEY` вставьте **anon public** ключ из Settings → API (не service role).
3. В SQL Editor выполните `supabase/scores.sql`, затем `supabase/classroom.sql`.
4. Перезапустите `npm run dev`, чтобы Vite подхватил `.env`.

Если ключ пустой, DNS не резолвится или запрос зависает, приложение **не падает**: на экране появляется сообщение, данные остаются в этом браузере.

Ожидаемые таблицы класса:

| Таблица | Смысл |
| --- | --- |
| `classroom_quizzes` | викторины учителя (`questions` — JSON) |
| `classroom_rooms` | код из 6 цифр, режим, снимок вопросов |
| `classroom_attempts` | имя, баллы, процент, время, промахи |

## Структура

- `index.html` — оболочка страницы
- `src/main.js` — игровой цикл: таймер, плеер, микрофон, вход в комнату
- `src/classroom.js` — Supabase + локальный запасной путь
- `src/store.js` — localStorage и синхронизация вкладок
- `src/screens-home.js` / `src/screens-teacher.js` — экраны ролей
- `src/questions.js` — встроенные колоды
- `src/pitch.js` — высота голоса
- `src/style.css` — тёмный музыкальный интерфейс
- `supabase/scores.sql` и `supabase/classroom.sql` — схема и RLS
- `public/audio/`, `public/images/`
- `scripts/generate-audio.py` — генератор фрагментов
