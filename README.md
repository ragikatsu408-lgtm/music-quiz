# Музыкальная викторина

Веб-игра на Vite (HTML, CSS, vanilla JavaScript): слушаете короткий фрагмент и выбираете одно из четырёх названий, пока идёт таймер.

Фрагменты — синтезированные публичные мелодии (народные песни и произведения с истёкшим авторским правом). Они лежат в `public/audio/`, ключи и внешние API не нужны.

## Как запустить локально

Нужны Node.js 20+ и npm.

```bash
npm install
python3 scripts/generate-audio.py   # если WAV-файлов ещё нет
npm run dev
```

Откройте адрес, который напечатает Vite. Dev-сервер слушает порт **46231**.

Сборка:

```bash
npm run build
npm run preview
```

## Как играть

1. Нажмите «Начать игру».
2. Слушайте фрагмент (кнопка «Слушать фрагмент», если браузер не дал автозапуск).
3. Выберите один из четырёх ответов за 15 секунд.
4. В конце раунда — счёт и разбор каждого вопроса.

## Структура

- `index.html` — оболочка страницы
- `src/main.js` — экраны, таймер, плеер, подсчёт очков
- `src/questions.js` — вопросы и тексты
- `src/style.css` — оформление (десктоп и мобильный)
- `public/audio/` — WAV-фрагменты
- `scripts/generate-audio.py` — генератор тех же фрагментов
